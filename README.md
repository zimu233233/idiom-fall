# 成语下落 · 八尺书生坠字渊

按《游戏设计书.docx》实现的纯前端 HTML5 游戏：竖屏"青绿手卷"风成语下落游戏。
宣纸底、矿物色（石青/石绿/朱砂/赭石/金泥）、书法字体，主角为撑油纸伞的青衫书生。
无需构建、无需服务器——**双击 `index.html` 即玩**（桌面键盘 + 手机触屏滑动）。

## 缘起

书生读破万卷，偏偏口拙——话到急处，字总绊在舌尖，旁人早替他说完了下半句。他只剩点头。

这一夜他伏案睡去，一脚踏空，从云端坠进一幅青绿长卷，轻得像一滴墨落入宋人山水。青衫、书箱、一把朱伞，坠过云海、松涛、幽谷、深潭，深度以丈计。风声愈急，他心里只剩一个念头：坠、坠得再急，也要把每个成语，好好说完。

游戏里的每一件事，都是这场梦的一部分：

| 画面 | 梦里 |
| --- | --- |
| 落对一字，字"盖"进画卷 | 他终于把这一字念完整了 |
| 气息（生命） | 说话要攒的气：念对回一口，念错一窒 |
| 错字如涟漪散去 | 情急之下念岔了字——不怪他，重来便是 |
| 浮石自沉 | 踟蹰太久，梦境塌了一角 |
| 学富五车 | 连着念顺了几条，胆气也回来了 |
| 搁笔（暂停） | 梦里小憩，画卷静候 |
| 卷终题跋（结算） | 气息用尽、梦醒时分，在卷尾题下这一梦 |
| 再展一卷 | 再睡一觉，再入一梦 |

开始界面「卷首 · 缘起」可重读这段故事；结算评语里的「书生梦话」，是他在梦里说出口的话。

## 结算评语与分享

结算页评语由五个文案池抽取组合（素材 1000+ 句，全组合千万级）：

| # | 池 | 句数 | 触发条件 |
| --- | --- | --- | --- |
| 1 | 数据行 | — | 固定「深度 X 丈 · 成语 Y 个 · 积分 Z」（非抽取） |
| 2 | 称号句 | 7 档×30 | 按积分落档：0 / 500 / 1500 / 3000 / 6000 / 12000 / 25000，档内随机 1 句；档名【白丁书生→翰林大学士】同档显示 |
| 3 | 深度句 | 5 池×40 | 档位**随画卷段界派生**：渊口（0～松涛起点⅓）/ 云海（至松涛起点 1500）/ 松涛（至幽谷起点 3000）/ 幽谷（至深潭起点 5000）/ 深潭（以上），池内随机 1 句；调参台改界即跟随 |
| 4 | 准确率句 | 4 档×40 | 按正确率落档：0 / 60% / 80% / 93%，档内随机 1 句 |
| 5 | 彩蛋 | 396 | 70% 概率出现，全池随机 1 句；出处：字渊传闻 / 字渊风物 / 深渊公告 / 书生日记 / 书生心得 / 书生梦话 / 墨客题壁 |
| 6 | 小贴士 | 50 | 每局必出，随机 1 句 |

分享书签/文案另有一套**专属池**（不与评语混抽）：

- **专属分享句**（每卡 1 句）：特殊成就优先覆盖，自上而下首个命中即用——新纪录（isBest）＞ 错字 ≥12（自嘲求助）＞ 零错字 ＞ 深度达深潭起点（默认 5000 丈）＞ 最高连击 ≥12 ＞ 兜底按称号七档各配的"晒"句（声口从白丁自嘲到翰林傲视）
- **挑战句**（每卡 1 句）：20 句随机，如「君敢来把成语说完吗？」「帮书生把下半句说完，来字渊。」
- **卡片版式**：★新纪录★ 徽记（破纪录时）→ 品第 → 四项数据 → 专属句「」→ 挑战句 → 左下**二维码**（扫即入坑，js/qr.js 自实现字节模式 + 里德-所罗门纠错 + 8 掩码择优）→「扫码 · 展卷」竖排小字 → 落款印
- **分享文本**（Web Share / 剪贴板）：`【称号】坠入字渊 X 丈 · Y 条成语。「专属句」——挑战句 游戏地址`

## 玩法

- 主角（撑伞书生）持续下落，每层浮石平台随机分布汉字（1 个正确字 + 2~3 个干扰字）
- **按顺序**落在四字成语的每个字上，顶部印章进度实时显示已收集字、拼音（分色）与释义朱签
- `←`/`→`（或 `A`/`D`）：平台上首次按键 = 向该侧跳起；**按住不放 = 撑伞滑翔减速**（手机：左右滑动起跳，手指停留减速）
- 当前目标字有**朱批圈 + 引路蝶**提示（随深度渐隐）
- 选对一字：主角小跳一下、该字平台墨染消散；+0.5 生命、连击加一
- 生命 100 点随时间流失：消耗速率按 **S 曲线**随深度从 0.1/秒升至 1/秒（默认 5000 丈深潭起点封顶，前缓中陡后缓），气息条随血量降低由石绿连续渐变为朱砂
- 选错字：扣血随深度渐增（浅层 -1，默认 5000 丈深潭起点起 -3 封顶，初期增长慢）、涟漪散字（无红闪震屏），弹回上一层、连击清零——**成语进度保留，继续选当前字**
- 通关掉落的铜钱/道具在下落途中会被**无字平台接住**停靠，主角碰触即拾取；所靠平台碎裂则恢复下落
- **错过一层（坠落越过当前字的平台）不判错**：进度保留，当前字的平台在下方自动补出，继续即可
- **停滞碎裂不再作废进度**：同一平台停留超 3 秒平台碎裂（浮石自沉）、-1 生命、清连击，但成语进度保留
- 连击每 +1 提升积分倍率 0.25×（上限 3.5×）；拼完整成语获高额通关积分并掉落方孔铜钱/道具
- 连续 3 个成语零失误零停滞 → **学富五车**：8 秒减速下落 + 积分翻倍（暖金光晕 + 银杏叶飘落）
- 深度以"**丈**"计，随坠落历经四段色调流转：云海晨雾 → 松涛午晴 → 幽谷暮色 → 深潭星蓝（默认边界 **1500 / 3000 / 5000 丈**，可在调参台「画卷四段」组实时调整，画面、里程碑与结算深度评语档随之联动）；**每跨越一个分区，难度段号额外 +3**（调参台「分区难度加成」可调，0=关闭），跨段瞬间干扰字、词库与下落极速同步上一个台阶
- 道具（快捷键 1/2/3 或点击多宝阁）：`减速表`（5 秒慢速）· `排雷锤`（清除下方 4 层错误平台）· `生命树叶`（+30 生命）
- 生命归零进入结算：长卷题跋式结算 + 宣纸书签分享卡，按深度/成语数/正确率生成动态评语（**素材 1000+ 句**、组合千万级），分享卡带专属分享句、挑战句与**扫即入坑的二维码**（Web Share / 截图下载降级）
- **首次打开有"展卷"加载动画**：书法字体等资源全部就绪后才放行开局（弱网 8 秒兜底），开始按钮在加载完成前不可用

> 注：①"错过层继续"与"停滞保留进度"为 2026-08-20 试玩后的调优（设计书原版为进度作废）；②2026-08-22 调优：选错字进度同样保留、扣血改为随深度 1→3 渐增、道具可被无字平台接住、气息条连续渐红。以本 README 为准。

## 手机端布局（≤880px 自动切换）

- 顶部：印章 logo + 成语印章进度条（拼音 + 释义朱签）
- 画卷上方**数据带**：气息 HP 胶囊 + 分数/连击倍率/深度（丈）/成语数
- 画卷底部：多宝阁三道具按钮横排
- 右上角朱砂"**卷**"字印章按钮 → 点开抽屉面板（词笺 / 成语图鉴 / 卷中物），**打开抽屉时游戏自动静默冻结，关闭后无缝续玩**；点 ✕ 或遮罩关闭
- 左栏战绩与旅程信息由数据带与抽屉承载，不再隐藏丢失

## 数值调参台（开发者专用）

改数值不用改代码，入口对普通玩家隐藏：

- **本地双击 `index.html`（file://）**：始终可用
- **线上（GitHub Pages）**：默认隐藏；首次访问带上 `?dev=砚` 解锁并记住本机（之后同浏览器再访无需带参），`?dev=0` 退出开发者模式
- 密钥定义在 `js/tuning.js` 的 `DEV_KEY`，可自行修改。纯前端方案只隐藏入口、挡不住翻源码的人，不构成安全边界

解锁后（开始界面点「调参台」按钮，或 `?tune=1` 直接弹出）：

- 覆盖 46 项参数（物理跳跃/平台节奏/生命消耗与错字扣血曲线/计分连击/学富五车/道具/难度词库与分区梯度/画卷四段边界），**每项附详细说明**：作用含义、单位、默认值、调大调小的影响
- **改动立即生效**，进行中的对局同样实时变化；附带「生命消耗/秒」「错字扣血」两张随深度变化的曲线预览图，改参数即刻重绘
- 「保存本机」后下次打开自动套用（localStorage）；「恢复默认」一键还原；「导出 JSON」可把改动发给开发者固化为默认值
