# 成语下落 · 八尺书生坠字渊

按《游戏设计书.docx》实现的纯前端 HTML5 游戏：竖屏 8-bit 水墨风"成语深渊"下落游戏。
无需构建、无需服务器——**双击 `index.html` 即玩**（桌面键盘 + 手机触屏滑动）。

## 玩法

- 主角（像素书生）持续下落，每层平台随机分布汉字（1 个正确字 + 2~3 个干扰字）
- **按顺序**落在四字成语的每个字上，顶部进度条实时显示已收集字、拼音与释义
- `←`/`→`（或 `A`/`D`）：平台上首次按键 = 向该侧跳起；**按住不放 = 滑翔减速**（手机：左右滑动起跳，手指停留减速）
- 选对一字：主角小跳一下、该字平台墨染消散；+0.5 生命、连击加一
- 生命 100 点随时间流失（越深越快）；选错 -3 并弹回上一层、连击清零、**该成语从头再选**
- **错过一层（坠落越过当前字的平台）不判错**：进度保留，当前字的平台在下方自动补出，继续即可
- **停滞碎裂不再作废进度**：同一平台停留超 3 秒平台碎裂、-1 生命、清连击，但成语进度保留
- 连击每 +1 提升积分倍率 0.25×（上限 3.5×）；拼完整成语获高额通关积分并掉落金币/道具
- 连续 3 个成语零失误零停滞 → **学富五车**：8 秒减速下落 + 积分翻倍（金色光环）
- 道具（快捷键 1/2/3 或点击右栏）：`减速表`（5 秒慢速）· `排雷锤`（清除下方 4 层错误平台）· `生命树叶`（+30 生命）
- 生命归零进入结算：按深度/成语数/正确率生成动态评语（数十万种组合），支持分享（Web Share / 截图下载降级）

> 注：其中"错过层继续"与"停滞保留进度"为 2026-08-20 试玩后的调优（设计书原版为进度作废），以本 README 为准。

## 目录结构

```
index.html          入口（双击打开）
css/style.css       8-bit 水墨风样式（三栏像素街机布局）
js/                 游戏脚本（传统 <script> 加载，file:// 可用）
  data/idioms.js    全量词库（45,410 条四字成语：字|拼音|释义）—— 生成物，勿手改
  data/common.js    常用成语表（1,017 条，前期关卡用）—— 生成物，勿手改
  utils.js idioms.js input.js audio.js effects.js camera.js
  player.js platforms.js items.js scoring.js hud.js game.js
  settlement.js main.js
build_idioms.py     词库预处理：从 全_output_拼音_解释.csv 重新生成上面两份数据
test/run-tests.js   无头验收测试（M0-M8 全量断言）
```

## 开发

```bash
# 重新生成词库（修改 CSV 或常用表后执行）
python build_idioms.py

# 运行验收测试（70 项断言）
node test/run-tests.js
```

### 调试 / 演示 URL 参数

| 参数 | 作用 |
| --- | --- |
| `?q=画龙点睛` | 指定本局第一个成语 |
| `?autostart=1` | 打开页面自动开局 |
| `?demo=play` | 自动驾驶演示（自动落正确字） |
| `?demo=wrong` | 自动驾驶（专落错字，演示惩罚路径） |
| `?demo=idle` | 挂机演示（演示停滞碎裂机制） |
| `?debug=1` | 控制台输出词库抽样 |
